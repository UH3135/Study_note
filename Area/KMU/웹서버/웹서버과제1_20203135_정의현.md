## 과제 1 간단한 웹서버 구현
### 문제
아래 config 디렉토리의 urls.py 문제 코드에서 에러를 수정하기 위해 할 수 있는 코드를 기술하시오.

현재 에러 메시지를 확인해보면 NameError: name views is not defined라고 적혀 있습니다.

즉, 이 에러는 현재 views가 정의되어 있지 않기 때문에 발생한 에러입니다.

Django 시스템은 Client가 요청한 URL을 확인하고 config directory의 urls.py를 확인하고 urlpattern에 적혀있는 함수를 실행시키게 됩니다. 이때 config파일의 urls.py를 확인해서 url 경로가 없거나 안내되는 함수가 제대로 설정되어 있지 않으면 오류가 발생합니다. 그래서  /mysite_hw1/config/urls.py에 ```from config import views```를 추가해서 config의 views파일의 index함수를 제대로 가져오도록 바꾸어 주었습니다.
