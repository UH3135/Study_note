## Deep Feedforward Network
### Function
- 만드는 방법
	- 조건문, 반복문  등 이용 -> 인간의 방식
	- 입력을 바탕으로 숫자 변환시키고
	- 층을 쌓고 긴 배열 형태로 리턴
- 각각의 층끼리의 계산
	- 백테와 행렬의 계산
	- 모든 선형함수는 행렬로 구현이 가능
	- 즉, 선형함수를 토대로 계산
- 손실함수
	- $loss(ytrue, ypred)$ 
	- 결국 목표는 $arg min(loss)$
- 미분
	- 다항함수는 근의 공식이 없다
	- 수치해석을 배우는 이유 -> 어떻게든 풀기 위함
	- 고점과 저점을 찾는 방법
- 뉴턴
	- 함수를 기울기를 이용해서 직선을 만듬
	- 만약 차이가 크면 다시 찾아봄
	- 이후 직선함수의 근 찾기
	- 직선 긋기를 n번하면 무조건 근을 찾을 수 있다
	- 그 결과 loss를 최적화하는 함수를 찾을 수 있다.
- 그레디언트 기반 최적화
	- loss는 일종의 cost 함수이다
	- $l^`(𝜽) = l({Q+e)}-l(𝜽) / (𝜽 + e) - 𝜽$
	- 결국 경사에 따라 이동
- 𝜽는 어떻게 구할 것인가?
	- $𝜽 <- 𝜽 <- εsign(l'(𝜽))$
	- 기울기를 토대로 구한 일차방정식을 보고 방향을 결정
	- sign의 방향의 반대로 이동해라
	- 너무 많이 가면 값을 놓칠 수 있으니 조금 천천히 가라
- 이론적으로는 변곡점에 들어갈 것이라 예측
	- 그런데 아니었음
- Gradient는 뭐니?
	- 우리는 loss function을 최적화하는 최소값을 찾고 싶음
	- loss = (W11, W22, ... ,) -> float
	- float를 최소화하면 함수가 최적화된 것
	- 미분시 결과는 숫자
	- 입력이 여러개 -> float
		- 미분은 어떻게 할까?
			- 다른 x는 전부 고정이라고 생각 (편미분)
			- $⊿y/⊿x_3$ -> 이걸 모든 x에 대해서 적용
			- 나온 결과를 모은다 -> 벡터 == 그레디언트 벡터
#### 그래디언트
- 미분의 특성을 그대로 가지고 있음
- 이동시키면서 찾는다 -> learning rate
- loss가 0에 가까울 때까지
## Linear Regression
- 우리는 모델을 생성
- $y = W^Tx$ 
- 이 모델은 W라는 값들을 얻고 싶다
### 확률 모델
### 확률 사용의 이유
- 입력에 정답이 존재하지 않음
- PMF -> 확률을 함수로 표현
- Joint 확률
	- 입력을 두 개 받음 -> 두 조건이 만족했을때의 확률
- marginal probability
	- 마진화 -> 이차원의 공간에 정의된 확률에서 일차원으로 바꾸고 싶음
	- 두 확률을 더하면 됨
- 이걸 이용해서 조건부 확률을 구함
