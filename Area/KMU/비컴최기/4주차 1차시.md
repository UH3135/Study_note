## Autoencoder
- self-supervise -> 스스로 학습
- unsupervised 학습 -> 결과(정답)이 존재하지 않음
	- 쉽게 사용이 가능
	- 만약 supervised 학습이 필요하면 더 뛰어난 개체가 정답을 만들어줘야 함
- $x -> f -> x'$
- 이제 x와 x'를 비교한다 -> Loss 확인
- 정보량이 적을 거라고 가정하고 갯수가 적은 벡터숫자로 줄이고 데이터를 재현해봄
- 함수를 조각내서 꾸미자
	- encoder - decoder
	- 즉, 합성함수와 비슷하다
- loss를 두 값의 차이를 계산하면서 구함
- 그레디언트를 이용하여 loss를 줄임
- 편미분을 진행해서 $d_{theta, pie}loss$
- 이게 역전파이다
- minibatch 단위로 묶는다
	- 왜? 처음부터 끝까지 다 보는 게 좋음
	- 왜? 전부를 이용해서 그래디언트를 계산하면 훨씬 정확한 답이 나옴
	- 그러나 너무 많은 양이기때문에 minibatch로 나누어서 조금씩 구함
	- step과 epoch
		- step은 한번 똑똑해지는 정도
		- batchsize를 기본으로 한다
		- epoch는 모든 데이터를 순회했을떄
	- 각 batch를 개별적으로 접근할 수 없음
		- iter를 사용해서 iterator를 만들어야 접근이 가능하다
	- layer에는 하나의 이미지가 들어간다고 가정
		- 즉, batch가 적용되지 않음
		- 
	- theta는 인코더에서 학습시킬 부분
	- pie는 디코더에서 학습시킬 부분
		- 근데 둘 다 미분하기에는 너무 많다
		- 그래서 일부만 미분하자
	- batch는 클수록 좋지만 너무 많은 인자가 생겨서 한계가 있다
	- batch를 설정하면 GPU로 여러개를 돌리기 때문에 minibatch 단위로 돌아간다
