## 확률과 정보 이론
- Joint Probability
	- 두 개 이상의 사건이 일어날 확률을 계산하는 방법
- Marginal 확률
	- 한쪽으로 밀어버리는 확률
	- 즉, 하나만 생각하는 확률이다
- 조건부 확률
	- 이미 일어난 일에 대해서 확률을 계산
	- 확률의 특징은 합쳐서 1이다
		- 조건부확률은 분모를 1로 만들어서 계산
- 실제 적용
	- P(a,b,c) = P(a|b, c)P(b,c)
		- 내가 b, c 확률을 알고 있으니깐 b, c가 일어난 이후 a의 확률만 알면 a, b, c 모든 확률을 알지 않나?
### 확률 밀도 함수
- 특정 값의 이벤트가 생길 확률은 0
- 특정 히스토그램을 범위를 0에 가깝게 하면 나오는 그래프
- 확률은 결국 범위에 대해서 결정된다
- 높이는 뭐니?
	- 그럴거 같다: likelihood
	- 즉, x에서 뽑는데 높이가 높은 곳이 뽑힐 거 같아
## Conditional Independence
- 컨디션 없이도 둘이 같게 나오면 둘은 independent하다
- 컨디션이 동일할 때 둘이 같게 나오면 서로 independent하다
- Expectation: 가중치 합 $𝔼_{x-p}[f(x)]$ 
	- f(x)는 돌린 함수
	- 밀도함수에서 하나 뽑아서 함수에 주고 나온 출력값
- 모든 경우에 대해서 돌리면서 가중치합을 계산하는 것
### sigmoid
- 0보다 크면 1, 0보다 작으면 -1로 붙이는 함수 단, 미분 가능하게 만들었음
### 베이즈 규칙
- $P(x|y) = \frac{P(y|x)P(x)}{P(y)}$ 
- 우리의 함수는 x가 주어졌을떄의 확률을 계산
- $y=f(x)$ 가 $P(y | x)$와 동일
- $P(x, y) = P(x | y)P(y) = P(y | x)P(x)$ 를 이용해서 문제 해결
- 출력이든 입력이든 알고 있으면 확률을 생성할 수 있음 -> 알고 있는 부분은 Evidence로 간주
- 사전 지식(pre-trained model)을 활용하면 더욱 비슷하게 나올 수 있다.
