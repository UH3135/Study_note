## Deep Generate Model
- 함수를 정의
- 기본적으로 미분을 통해 함수 학습 -> 부드러워짐
	- 즉, 아직 학습 안 한 부분도 예측이 가능함
### VAE
- 암기식
- 모든 데이터를 때려 넣고 맞는지 자가 검증
### GAN
- 자기주도식 (채점서버와 같음)
	- 창의력을 요하는 경우 뛰어남
	- 답의 정답 여부만 알려줌
- 랜덤한 데이터를 출력하고 이를 평가 받음
- 결과가 들쭉날쭉함
## Learning Algorithm
### 머신러닝
- 인간의 학습을 기계한테도 적용
- 경험론(Experience)을 기반으로 진행
- 특정 일(Task)을 잘하게 됨
- 평가 지표(Performance)가 있어야 잘 학습할 수 있음
### Task
- 내가 추구하는 목표, 원하는 결과물
- 코딩에서 내가 짜는 함수의 특별한 점?
	- 결국 int나 float를 리턴하지 않아?
		- 즉, classification이나 regression으로 귀결됨
	- 이 두 가지 일을 조합하여 다양한 일을 진행
### Performance
- 정량적인 평가
	- 숫자를 이용하여 확실하게 표현 + 어떤 일에 대해 얼마나 잘하는 지 평가
- Classification Tasks
	- 얼마나 정확하게 맞췄니?
		- 객관식에서 아예 틀린 경우에는 점수가 X. 이와 유사함
		- 즉, 부분점수는 없다.
- Density estimations
	- 결과가 약간은 달라도 점수를 줌 
	- 주관식 문제
- Test Set과 Train Set은 달라야 한다
### Experience
- Task와 연관되어 있는 Data를 모아야한다.
- Supervised 알고리즘
	- 인공지능이 학습되기 전에 인간이 정리해놓은 데이터를 바탕으로 학습하는 알고리즘
	- 학습이 쉬움 그러나 비용이 많이 들게 됨
	- 조건부 확률을 활용
- Unsupervised 알고리즘
	- 답을 주어주지 않아도 데이터가 답이 존재할 때
	- 데이터가 특정 형태를 가지고 있어야 함
- Semisupervied 알고리즘

## Neural Network 기초
### Deep Feedforward Networks
- 입력을 넣은 것 -> feed 
- 데이터가 진행되면서 함수가 실행되는 것 -> forward
- 내가 원하는 기능 -> $f^*$ 라고 칭
- 내가 구현한 기능 -> $f𝜽(x)$ 
#### 기능은 어떻게 구현?
- 여러 층의 layer를 쌓아서 구현
- layer를 $𝜽$로 대표해서 작성한다
- 학습이 되면 $𝜽$가 업데이터가 됨
- 근거는 $f^*$랑 차이를 중심으로 구현한다
#### Feedforward는 어떻게 진행되는가
- 각 layer에서 가중치를 더한 값이 합쳐져서 다음에 전달
- 은닉층의 갯수는 마음대로
- 입력인자 -> placeholder
- 계산하는 로직 = layer
- 가중치 합은 행렬의 내적으로 나타낼 수 있음 : $H*W$
- 입력에 행렬을 곱해서 결과를 내는 것 -> 아주 기본적인 행렬
> loop unrolling 
> - for-loop를 없앤것
> - 병렬처리가 가능해짐 -> AI는 병렬처리가 가능

> 수학에서는 벡터를 세워쓰지만 Numpy는 row기반의 데이터가 기본이므로 눕혀서 쓰게 된다
> 즉, 벡터(눕혀진) * 행렬 = 벡터(세워진) 형태를 자주 볼 것이다
#### 활성 함수
- 행렬은 linear적인 성향이 있음
	- 나중에 은닉층을 추가했을때 성능을 올릴 수 있게 활성 함수를 추가
- 대표적으로 ReLU, Sigmoid 함수가 존재한다
#### 손실 함수
- 잘했냐 못했냐에 대한 평가
	- 정답과 거리가 멀수록 더욱 크게 감점하는 등을 통해서 성능 개선이 가능
- 최적화 함수는 내가 만든 함수의 예측값과 정답을 비교해서 손실함수의 값을 최소화 되는 값이다.
	- $𝜽opt = argmin(loss(y(true), y(pred)))$
